# The release (`/goa2/v1/`, branch `release`)

The final, real version of the game, assembled from 1.0 plus 2.0's features —
one segment at a time, each tested here before the next. Not live: friends keep
playing 1.0 at `/goa2/` until this is finished, then `/goa2` switches to it.

How every segment goes: port it from 2.0 (adapting to 1.0's screens where they
differ) → build + tests → deploy to `/goa2/v1/` → a real test there (two tabs
or friends) → tick it off. Fixes the live game needs go into 1.0 AND here.

## Segment 8 — the BUILD PLAN (agreed design, 2026-10-06; build from here)
The approved design is the mockup page `mockups/preview-hud2.svelte.txt` (copy it to `src/routes/preview-hud2/+page.svelte` — that folder is git-ignored — and open `/preview-hud2?v=expanded&n=4|6&s=plan|rev`; query switches are listed at the top of its script). Build it as the personal "2.0" HUD (Classic stays as it is), expanded layout first, on 1440×900 design px.
1. **Top bar** (full width between the ☰ and the wheel button): Round N + 4 turn pips · Titan Life box (solid blue tint, tokens on ONE line, no words / counts) · the tie-breaker coin (74 px, centred, juts out above and below) · Atlantean Life box (orange) · Wave N + the orange/blue wave tokens. Life / wave / coin flips as before (everyone sees them).
2. **The beam** under the bar, round the coin's bottom: resting points = centre (coin bottom), the brass diamond halfway across each Life box (beaches), the box ends (thrones); between them it is a tug-of-war of minion health in the zone (a team losing minions is pushed back to its own end; reaches the next point when its last minion falls). Should glide when it moves. Effects → Beam (personal, off by default) = spark + pulses running from each end towards the clash; off = plain coloured bar.
3. **Order row** under the bar: "Planning" + one dot per player, then the initiative banners after the reveal (hero first, the player small; 6p: player caption top-right — fix the overlap with long names).
4. **Side boards** (from y 194): enemies left, your TEAMMATES right (no board for you — the dash has it). Header one line: portrait in level ring · HERO name (white) · player · Lv · hand count. Turn slots I–IV (cards / backs) + discard. Six stat bubbles (3-segment rims for atk/def/init). Faint full hero splash behind. No gold / markers (they are on the full board).
5. **Chronicle** = the last slot of the right column, board-sized and fixed: GOLD head (host: Undo bubble; others: team crest · "Chronicle" · the faces of heroes with effects, one per hero, ring split per effect + count) over a SILVER log; lines = player-colour dot + hero name (no player names); newest at the bottom (column-reverse scroller). Hover the faces → "Effects in play" beside it, staggered (hero line, effects a tab in), anchored to the box bottom.
6. **The dash** (compact, 88 tall, centred): left cap = portrait with the 8 level arcs as its outer ring (no gold ring) + initiative badge + crown/markers · hero / player / coin with the number on it, ± · stats 3×2 · wells I–IV · discard · deck (count) · ult slot · tools 3×2 (radius, ping, tokens / auto-hide, fan↔side-by-side, dock) · docked ribbon rack (DockHand) when docked · right cap = the gold action ring (words from `order` in CardLayer; Commit's 2nd line = the card name only; 2nd lines centred). Undocked hand over the board, clipped at the dash.
7. **Pieces**: the 1.0 pills round the token, clockwise from 12 (12·3·6·9): enemy hero Attack · Defeat[coin] (confirm = one bar above: Attack X, coins / assist / Life, Attack ✕); your hero Clear · Defeated · Remove; minion Defeat[coin] · Remove; heavy Immune on top.
8. **Attack splash** for everyone (DefeatSplash look, both heroes in colour): enemy attacks yours → "Enemy attacks Ally" (from the left); yours attacks → "Enemy attacked by Ally" (from the right). Then the usual defend / defeated flow and the defeat splash.
9. **Control wheel** (top right): hub Recenter; ring Effects (Rims · Zone · Waves · Beam · Island) · Zoom (In / Out) · Expanded/Compact (everyone) · Views · Spawn (six minions; host, greyed for others) · Push (Titan blue / Atlantean orange → green Confirm / red Cancel; host, greyed for others) · Rotate (Left / Right). `WheelItem.tone` is already in ControlWheel.
10. **☰ = the game lobby**, centred: room · code · connection, both teams (Kick), watchers (Approve / Deny), Your HUD (2.0 / Classic / Custom), host: End the game, Leave.
Then: compact view, other screen sizes, phone (segment 9). Card view + splashes: talk with the user first. REMIND THE USER: they want to revamp how defence / forced discards work.
